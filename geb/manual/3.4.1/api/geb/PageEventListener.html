Package: geb

[Groovy] Interface PageEventListener

  • Implementations of this interface can be registered with Configuration to listen to certain Page events.

    See Also:
    PageEventListenerSupport
    CompositePageEventListener

      • void pageWillChange(Browser browser, Page oldPage, Page newPage)

        Called each time the browser's page instance changes. Note that this is not when the browser navigates to a new page, but when it's page object changes.

        Parameters:
        browser - The Browser instance for which the page instance is about to change
        oldPage - The Page instance currently set on the browser
        newPage - The Page instance which is about to be set on the browser
