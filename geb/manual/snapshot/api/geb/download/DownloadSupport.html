      • abstract HttpURLConnection download()

        Creates a http url connection to a url, that has the same cookies as the browser. Resolves the base and the uri to the current browser page

      • abstract HttpURLConnection download(Map options)

        Creates a http url connection to a url, that has the same cookies as the browser.

        Valid options are:

        • uri - the uri to resolve relative to the base option (current browser page used if null)
        • base - what to resolve the uri against (current browser page used if null)
